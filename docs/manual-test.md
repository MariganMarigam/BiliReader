# BiliReader — чек-лист ручной проверки (baseline, фаза 0)

Проверяется чтение (открытие EPUB/FB2, пагинация, темы, кегль, навигация, прогресс),
**встроенный словарь EN–RU**, **менеджер офлайн-модели перевода** и **режим удержания
строки** (`B13`–`B17`).
Словарь FreeDict EN–RU (~6.5 МБ) входит в сборку: одиночное слово даёт карточку
словаря офлайн, без сети (B17). Модель перевода в бандл **не входит**: её скачивают
из Settings → Language → *Offline engine* (≈ 1.06 ГБ, с huggingface.co), после чего
работает перевод удерживаемой строки. Перевод по выделению (попап B10) по-прежнему
зависит от выбранного Translation Service.

- Версия сборки: **0.1.0** (`apps/readest-app/package.json`)
- Платформа: Linux x86_64, рантайм CEF (не WebKitGTK)
- Артефакты: `target/release/bundle/{appimage,deb,rpm}/`
- Тестовые книги: `samples/` в корне репозитория

Ставьте отметку в колонке «Итог»: `OK`, `FAIL` или `—` (не проверялось).

## 1. Установка и запуск

### 1.1 AppImage (без установки)

```bash
cd target/release/bundle/appimage
chmod +x BiliReader_*.AppImage
./BiliReader_*.AppImage
```

- **Ожидаемо:** окно библиотеки появляется за 5–10 с, без диалога «нет прав» и без
  сообщений `panic` / `Traceback` в терминале.
- AppImage не требует root. Первый запуск может быть медленнее (распаковка в `/tmp`).
- Если окно не появилось: запустите из терминала и приложите его вывод к баг-репорту
  (см. §4). Проверьте, что `DISPLAY` указывает на рабочий X-сервер: `echo $DISPLAY`.

### 1.2 Debian/Ubuntu пакет

```bash
sudo apt install ./target/release/bundle/deb/BiliReader_0.1.0_amd64.deb
readest
```

- Пакет ставит `/usr/bin/readest` (имя исполняемого файла — `readest`, пакет — `bili-reader`).
- `apt install ./file.deb` (именно с `./`) сам подтянет зависимости из репозитория.
- Запуск также доступен из меню приложений (категория «Продуктивность»/«Офис»).
- Удаление: `sudo apt remove bilireader`.

### 1.3 RPM (Fedora/openSUSE)

```bash
sudo dnf install ./target/release/bundle/rpm/BiliReader-0.1.0-1.x86_64.rpm
readest
```

### 1.4 Dev-режим (из исходников)

```bash
scripts/bilireader-run.sh --cef   # приложение в окне, как в релизе
scripts/bilireader-run.sh         # только UI в браузере, http://localhost:3000
```

- Скрипт сам подхватывает nvm и rustup, проверяет системные библиотеки и печатает
  понятную причину, если чего-то не хватает.
- `--cef`: первый запуск 20+ минут (скачивается CEF и компилируется Rust), ~8 ГБ;
  дальше — секунды. `--desktop` — WebKitGTK, 10–15 минут и 2–3 ГБ.
- Остановка: `Ctrl-C` в терминале.
- Переопределить `DISPLAY` при необходимости: `DISPLAY=:0 scripts/bilireader-run.sh --cef`.

### 1.5 Релизная сборка (если артефактов нет)

```bash
scripts/bilireader-build-linux.sh
```

Скрипт печатает пути и размеры готовых `.AppImage` / `.deb` / `.rpm`.
Требуется ~8 ГиБ свободного места и 25–45 минут на холодном кеше.

## 2. Где взять книги

В репозитории уже лежат два файла — их достаточно для всех проверок ниже:

| Файл | Что внутри | Зачем |
|---|---|---|
| `samples/sample.epub` | EPUB 3, английский текст, 3 главы, оглавление (nav + NCX) | импорт, пагинация, типографика |
| `samples/sample-1251.fb2` | FB2 в кодировке **windows-1251**, русский текст, 3 главы | проверка автоопределения кодировки |

Обе книги короткие (несколько экранов), поэтому листать удобно.

Импорт: на экране библиотеки — кнопка **«+»** (Import) → **Import Books** → выбрать файл.
Альтернатива: перетащить файл в окно приложения. Книга появляется на полке с обложкой-заглушкой.

Свои книги можно положить рядом: `samples/` не является системным каталогом,
приложение читает файл из любого места.

## 3. Проверки

Каждая строка — отдельный сценарий. Если шаг не воспроизводится, фиксируйте номер (B1…B17).

| # | Проверка | Шаги | Ожидаемый результат | Итог |
|---|---|---|---|---|
| **B1** | Импорт EPUB | Библиотека → «+» → Import Books → `samples/sample.epub` | Книга появляется на полке за < 3 с, обложка и название «BiliReader Sample Book», ошибок нет | ☐ |
| **B2** | Открытие и пагинация | Клик по книге → читать 3–4 страницы вперёд | Текст читаемый, поля не обрезаны, номер страницы/процент внизу меняется, заголовок главы виден в начале главы | ☐ |
| **B3** | Листание с клавиатуры | `→` / `Space` / `l` — вперёд, `←` / `Shift+Space` / `h` — назад, 10 раз в каждую сторону; отдельно `PageDown` / `PageUp` | Стрелки и пробел листают по одной странице, без «перескоков» через главу и пустых экранов; `PageDown`/`PageUp` переходят к следующей/предыдущей секции (главе) | ☐ |
| **B4** | Листание свайпом/тачпадом | Горизонтальный свайп двумя пальцами по тачпаду или свайп по экрану (тач) | Страница перелистывается плавно, выделение текста не срабатывает вместо листания | ☐ |
| **B5** | Смена кегля | Нижняя панель → **Aa** (Font & Layout) → увеличить размер шрифта 16 → 22 → 16 | Текст перевёрстывается мгновенно (< 1 с), без обрезки строк и горизонтального скролла | ☐ |
| **B6** | Позиция при смене кегля | На середине главы 2 поменять кегль 16 → 22 | Остаётесь в том же абзаце (допустим сдвиг на несколько строк), книга не прыгает в начало | ☐ |
| **B7** | Смена темы | Панель **Aa** → Theme: Light → Dark → Sepia (и обратно) | Меняются фон и цвет текста всей книги и интерфейса; текст остаётся контрастным; выбор сохраняется | ☐ |
| **B8** | Прогресс | Нижняя панель: полоса прогресса и проценты; пролистать до конца главы 1 | Процент растёт монотонно, полоса заполняется; в конце книги ~100 %; клик по полосе переходит в нужное место | ☐ |
| **B9** | Импорт FB2 с кириллицей | Библиотека → «+» → `samples/sample-1251.fb2` → открыть | Название «Образец для BiliReader», русский текст **без кракозябр** (`Ðÿîáðàçåö`, `????`), 3 главы в оглавлении | ☐ |
| **B10** | Выделение слова | Выделить слово мышью/долгим тапом в любой книге | Появляется попап/меню выделения (словарь, копировать, подсветка). Перевод в попапе зависит от выбранного Translation Service (см. B16); приложение не падает | ☐ |
| **B11** | Перезапуск | Закрыть приложение на середине главы 2 → запустить снова | Библиотека содержит **обе** книги; открытая книга продолжается с того же места (допустим сдвиг в пределах абзаца) | ☐ |
| **B12** | Файлы на диске (для диагностики) | `ls ~/.local/share/com.bilireader.app/Readest/Books` | Каталоги книг на месте, внутри — файл книги и `config.json` с полем `progress`; в корне данных есть `library.json` | ☐ |
| **B13** | Менеджер моделей: скачивание | Settings → Language → Translation → **Offline engine** → **Download (1.06 GB)**, дождаться конца | Прогресс-бар показывает «скачано / всего», затем статус **Installed** и тост «Translation model installed»; загрузка идёт с `huggingface.co` (видно в логе запросов/сети), в `~/.local/share/com.bilireader.app/Readest/bilireader/models/` лежит `Hy-MT2-1.8B-Q4_K_M.gguf` (~1,06 ГБ), каталог `.tmp/` пуст | ☐ |
| **B14** | Менеджер моделей: прерывание/отмена | Начать Download и на ~10 % закрыть приложение; запустить снова, открыть Offline engine → **Download** ещё раз | После перезапуска статус **Not installed**, файла `.gguf` нет, недокачанный `<id>.part` лежит в `.tmp/`; повторная загрузка продолжается с места обрыва (счётчик не с нуля). Если сервер не поддерживает `Range`, загрузка начинается заново — это допустимо. Приложение не падает | ☐ |
| **B15** | Менеджер моделей: удаление | При статусе **Installed** нажать **Delete** → подтвердить в диалоге | Тост «Translation model removed», статус снова **Not installed**, `.gguf` удалён из папки моделей; повторное скачивание после удаления работает | ☐ |
| **B16** | Удержание строки (перевод предложения) | Settings → Language → Translation: включить **Enable Translation**, **Translate a Held Line**, Translation Service — встроенный офлайн-движок, Translate To — Russian. Открыть `samples/sample.epub`, зажать строку мышью на 0,4 с не двигая; затем вести вверх/вниз за границу строки; отпустить; кликнуть в области чтения | Строка подсвечивается полосами на всю ширину колонки, над ней открывается попап с исходным предложением и переводом (первый перевод после установки — несколько секунд, дальше из кеша). Смещение вверх/вниз переключает на предыдущее/следующее предложение, отпускание оставляет попап, клик по тексту закрывает. Короткий тап и свайп по-прежнему листают страницу. При включённом highlight quick action переключатель *Translate a Held Line* заблокирован с пояснением | ☐ |
| **B17** | Словарь EN–RU офлайн | Открыть `samples/sample.epub`, выделить (двойной клик) одно английское слово, например `dog`; отдельно проверить форму `ran` и отсутствующее в словаре слово | Для `dog` сразу открывается карточка **словаря** с переводами и частями речи (существительное и глагол), без сети и без spinner «перевод…»; `ran` находится по лемме → статья `run`; слово, которого нет в словаре, уходит в обычный переводчик (без падения и без пустой карточки) | ☐ |

> **Про отмену загрузки (B14).** Отдельной кнопки *Cancel* в панели нет: прерывание —
> это закрытие приложения или потеря сети. Недокачанный файл всегда остаётся в
> `<models>/.tmp/` и никогда не попадает в рабочую папку под именем `.gguf`.
> Коды ошибок панели: `network`, `checksum`, `disk`, `cancelled`, `unsupported`.

> **Про путь в B12.** Если в настройках задан собственный каталог данных
> (Settings → Storage), путь будет другим. `~/.local/share/com.bilireader.app/Readest/`
> — путь по умолчанию для Linux.

## 4. Как сообщить о баге

Пришлите одним сообщением:

1. **Номер проверки** (B1…B17) и что именно сделали — по шагам.
2. **Что ожидали** и **что произошло фактически**.
3. **Скриншот или короткое видео** (для визуальных проблем — обязательно).
4. **Вывод терминала** — запускайте приложение из терминала, чтобы получить stderr:
   ```bash
   ./BiliReader_*.AppImage 2>&1 | tee ~/bilireader-run.log
   ```
   Для dev-режима: `scripts/bilireader-run.sh --cef 2>&1 | tee ~/bilireader-run.log`.
   Приложите последние 50–100 строк — там видно панику Rust/CEF.
5. **Версию и окружение:**
   ```bash
   echo "$(uname -srm)"; echo "DISPLAY=$DISPLAY"; echo "XDG_SESSION_TYPE=$XDG_SESSION_TYPE"
   ./BiliReader_*.AppImage --version 2>/dev/null || true
   ```
   Версия приложения — в Settings → About (или `0.1.0` для этой сборки).
6. Если приложение установлено из `.deb` и падает при старте — добавьте `journalctl`:
   ```bash
   journalctl --user -n 100 --no-pager
   ```

Если книга не открылась — приложите сам файл (или его первые 100 КБ), если это не
приватный документ.

## 5. Что в этот baseline НЕ входит

- Словари, кроме встроенного FreeDict EN–RU (B17), пользовательские словари и импорт `.dict`-бандлов, TTS, синхронизация, AI-функции (следующие фазы).
- Онлайн-переводчики и custom translators: проверяется только офлайн-движок (B13–B16).
- Удержание строки в вертикальной письменности и в шрифтах, переопределяющих отступы
  документа: подсветка строки там не поддерживается (попап работает).
- Android/iOS/Windows/macOS — отдельные сборки, отдельные чек-листы.
- Производительность на больших книгах (> 10 МБ) — отдельный замер, фаза 1.

Если что-то из этого не работает — это **не** регрессия baseline.
