# Архив планирования BiliReader

## Что это

Здесь лежит снимок исследовательских отчётов и планов, которые изначально
писались в `output/`. Каталог `output/` исключён из git через
`.git/info/exclude` и при клонировании или переносе проекта исчезает. Чтобы
обоснования решений и история разработки не пропали, документы скопированы в
репозиторий.

Тексты сохранены дословно; заменены только абсолютные домашние пути (на
`<project>`) и обновлена ссылка на этот архив. Поэтому файлы длиннее обычного
лимита в 250 строк — это осознанно: ценность архива в полном тексте, а не в
конспекте.

## Почему форк Readest

- Readest уже даёт Tauri v2 + Next.js + форк `foliate-js`, то есть ровно тот
  стек, который исследование признало лучшим для CSS-пагинации.
- В нём есть библиотека, темы, попап перевода, словарная инфраструктура и
  абстракция провайдеров — работу можно свести к офлайн-провайдеру и
  Rust-ядру, а не писать ридер с нуля.
- Цена — AGPL-3.0 на весь форк и обязанность публиковать исходники. Продукт
  открытый, поэтому цена принята; альтернатива — собственная сборка на
  `foliate-js`, которая заняла бы на 6–8 недель больше.

## Почему llama.cpp в процессе

- Отдельный `llama-server` — это второй процесс, порт, HTTP-хоп, CORS и
  супервизия. Встроенный движок убирает всё это, не меняя RSS: модель и так
  живёт в памяти приложения.
- `llama-cpp-2` вендорит C++ и биндинги, собирается под Android NDK и не
  требует ручного FFI; версия зафиксирована в `Cargo.lock`.
- Отмена делается атомарным флагом на каждый токен, а не убийством потока:
  `llama.cpp` не умеет прерывать prefill, но между токенами флаг виден.

## Почему каскад «словарь → быстрая MT → контекстная MT»

- Одно слово через MT — плохой ответ: нет части речи, списка значений и
  леммы. Словарь отвечает за единицы миллисекунд и pedagogically точнее.
- Короткая фраза не стоит 0.5–1.5 с ожидания LLM; для неё задумывался
  быстрый L2 (OPUS-MT/Bergamot). В 0.1.0 L2 пропущен, поэтому фраза сразу
  уходит в L3.
- Предложение и абзац требуют контекста и качества — это L3, Hy-MT2.
- Каскад даёт предсказуемую латентность: мгновенный словарь, затем
  ограниченный по длине L3, с кэшем на каждом уровне.
